  Minum — a minimalist Java web framework

  com.renomad:minum v11.0.2 (by Byron Katz, on Maven Central). ~7,000 lines of
  production code, zero runtime dependencies beyond the Java 21+ SDK — it ships
  its own web server, router, database, templating engine, HTML parser, logger,
  and test framework. The pitch is maintainability: comparable frameworks are
  141k (Javalin) to 1.08M (Spring Boot) lines including deps.

  Stated design constraints (CONTRIBUTING.md, docs/development_handbook.md): no
  reflection, no annotations, no "magic" — everything is plain method calls.
  Config lives in a single minum.config properties file. 100% statement/branch
  coverage is maintained as a hard rule, plus near-100% mutation-test strength
  via PiTest. TDD-driven, server-side-rendered/hypermedia-first.

  Layout — src/main/java/com/renomad/minum/ (209 java files)

  server + brig

  request.getRequestLine().queryString(),
  request.getBody().asString(...)/asBytes(...). Responses via Response.htmlOk,

  registerPartialPath for path parameters (discouraged; used mainly for

  Critical — security

  1. HTTP request smuggling via Transfer-Encoding: chunked —
  WebFramework.java:385
  The "unread body ⇒ close connection" guard only fires when contentLength() >= 
  0. Chunked requests have no Content-Length, so it's skipped, the body stays in
  the socket, and keep-alive survives. Reproduced live: one byte stream that a
  chunked-aware proxy reads as a single POST /noop returned two responses, the
  second being <p>SECRET-ADMIN-PAGE</p>. BodyProcessor.java:44 rejects chunked
  only if a handler calls getBody() — a 404 or body-ignoring handler never gets
  there. Fix: force isKeepAlive=false when a transfer-encoding header is
  present, and reject requests carrying both TE and CL (RFC 9112 §6.1).

  2. Symlinks escape the static-files directory — FileUtils.java:120-121
  toRealPath(LinkOption.NOFOLLOW_LINKS) on both sides makes the containment
  check purely lexical, while the read follows the link. Reproduced live: GET 
  /link.txt → TOP-SECRET-OUTSIDE-STATIC; GET /host.txt → contents of
  /etc/hostname. Literal ../ is still correctly blocked. Fix: drop
  NOFOLLOW_LINKS from both calls. Found independently by two agents.

  3. Range is never bounds-checked — Range.java:63-68 → Response.java:236-257
  Measured against a 100-byte file: bytes=200- → Content-Length: -100;
  bytes=0-9999999999999 → Content-Length: 10000000000000 (client hangs to

  RandomAccessFile.seek() after headers are sent. The first is an ordinary
  video-seek case, not just an attack. There's no 416 path at all. RangeTests
  covers only in-range values.

  4. %NULL% sentinel injects Java null into query maps and bypasses the 
  duplicate-parameter check — StringUtils.java:88-94, used raw at
  RequestLine.java:219

  defeats the framework's own duplicate-key rejection — parameter pollution past
  a security control. BodyProcessor.java:171 already guards this; RequestLine
  doesn't.

  5. SUSPICIOUS_PATHS= (empty value) bans every visitor to the homepage —
  Constants.java:270-280
